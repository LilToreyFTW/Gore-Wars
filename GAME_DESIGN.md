# Gore-Wars design notes

Blackharbor is a coastal metropolis where crews, compromised institutions, and ambitious newcomers compete for leverage. The vertical slice uses four resources: Stamina for training, Nerve for crime, Vitality for recovery, and Morale for effectiveness. Cash is integer credits in the prototype.

The command loop is objective → resource cost → risk → resolved outcome → progression → reinvestment. The first authored contacts are Mara Voss (fixer), Silas Quill (broker), Dr. Imani Vale (medic), and Rex Calder (racing organizer); Mara is playable in this milestone.
